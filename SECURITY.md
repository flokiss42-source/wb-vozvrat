# Политика безопасности

Не публикуйте уязвимости и действующие WB API-токены в открытых issue.

Для приватного сообщения используйте GitHub Security Advisory:
`Security` → `Advisories` → `Report a vulnerability`.

Если токен уже оказался в Git, issue, чате или логе, немедленно отзовите его в
кабинете WB и выпустите новый токен с минимальными read-only разрешениями.

Поддерживаемая версия: последняя версия ветки `main`.
