# WB Возврат

Локальный open-source аудит детализации финансового отчёта Wildberries. Он
выделяет операции, которые стоит проверить перед обращением в поддержку:
крупные удержания и штрафы, отрицательные или нулевые выплаты, дубликаты и
аномальную стоимость логистики.

## Запуск

Нужен Node.js 20+, установка зависимостей не требуется.

```powershell
npm.cmd run audit -- fixtures/demo.csv
npm.cmd test
```

HTML-отчёт появится в `reports/`. Исходный CSV никуда не отправляется.

На некоторых Windows команда `node` может быть перекрыта одноимённым системным
файлом, поэтому в примере используется `npm.cmd`, который выбирает Node.js из
установленной среды.

## Где взять данные

В кабинете WB Partners скачайте детализацию еженедельного отчёта реализации в
CSV. Названия колонок со временем меняются; адаптер поддерживает основные
русские названия и API-поля. Файлы `.xlsx` пока нужно сохранить как CSV UTF-8.

## Важно

«Потенциальный риск» — сумма операций для ручной проверки, а не гарантированная
компенсация и не юридическое заключение. Финансовый отчёт сам по себе не
доказывает потерю товара. Для этого понадобятся данные поставок, приёмки,
остатков, возвратов и компенсаций — это следующий этап проекта.

## Ближайший план

- импорт XLSX;
- безопасное подключение read-only токена WB API;
- сверка поставка → приёмка → продажа/возврат → остаток → компенсация;
- карточка доказательств и контроль срока обращения;
- кабинет с оплатой только за подтверждённый результат.
