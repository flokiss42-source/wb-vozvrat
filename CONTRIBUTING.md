# Участие в разработке

Спасибо за интерес к WB Возврат.

1. Создайте issue с описанием ошибки или предлагаемого правила.
2. Не прикладывайте API-токены, персональные данные и необработанные отчёты.
3. Добавьте тест, воспроизводящий изменение.
4. Запустите `npm.cmd test`.
5. Откройте небольшой PR с объяснением бизнес-логики и источником схемы WB API.

Новые правила поиска потерь должны работать консервативно: при неполных или
противоречивых данных результат блокируется, а не объявляется доказанной потерей.
